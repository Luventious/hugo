为了持续推出爆款车型，每家车企都会有一套持续稳定的产品研发流程。这里会探讨作为用户体验设计师，在整车研发流程中，能力地图需要到达哪些边界。



成熟的整车研发流程大体都离不开：产品线战略→单品定位→创意方案→目标设立→工程开发→评估验证。而用户体验不是独立的环节，而是渗透整个流程。而其中需要设计师/产品经理深度参与的是——1、产品企划；2、创意功能产出；3、体验评估

| 阶段 | 目标 | 子步骤 | 关键活动 | 工具/方法 | 输出物 |
| ---------- | ---------- | ---------- | ---------- | ---------- | ---------- |
| **1. 产品企划阶段**
(Planning) | 定义问题、收集需求，建立基础蓝图。 | 1.1 用户研究
1.2 市场分析
1.3 价值定义
1.4 需求定义 | - 访谈用户、调研NEV车主痛点（如充电时间、续航）。
- 分析竞争对手（如Tesla、BYD的产品）。
- 优先级排序用户需求。
- 评估技术可行性（如电池技术法规）。 | - 用户访谈/问卷（e.g., SurveyMonkey）。
- SWOT分析。
- 用户画像（Personas）。
- PESTEL分析（政治、经济、社会、技术、环境、法律）。 | - 用户需求报告。
- 产品路线图（Roadmap）。
- 需求规格书（PRD）。 |
| **2. 创意阶段**
(Ideation) | 生成创新想法，设计初步方案。 | 2.1 脑暴与idea生成
2.2 概念设计
2.3 原型构建
2.4 内部评审 | - 跨团队脑暴（如设计师、工程师、市场人员）。
- 绘制草图或数字模型。
- 快速构建低保真原型（如车内UI界面）。
- 反馈迭代初步想法。 | - 脑暴工具（e.g., Miro、MindMeister）。
- 设计软件（e.g., Figma、Sketch）。
- 故事板（Storyboarding）。
- SCAMPER方法（Substitute, Combine等创意技巧）。 | - 概念草图/模型。
- 低保真原型（Lo-Fi Prototype）。
- 创意方案集。 |
| **3. 评价阶段**
(Evaluation) | 验证方案，收集反馈，推动迭代。 | 3.1 用户测评
3.2 数据分析
3.3 迭代优化
3.4 最终验证 | - 模拟测试（如车内交互测试）。
- 分析使用数据（如眼动追踪）。
- 根据反馈调整设计。
- A/B测试最终版本。 | - 用户测试工具（e.g., UserTesting、Hotjar）。
- 量化指标（e.g., NPS分数、任务完成率）。
- 热图分析。
- 焦点小组讨论。 | - 测试报告。
- 优化建议。
- 最终UX设计文档。 |
